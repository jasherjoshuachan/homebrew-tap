# Homebrew tap

```bash
brew install --cask jasherjoshuachan/tap/headroom-bar
```

- [Headroom](https://github.com/jasherjoshuachan/headroom-bar): macOS menu bar app that shows how much of your AI plans you have left.

Not signed with an Apple Developer ID yet, so macOS asks you to confirm the first open (right-click, Open).
